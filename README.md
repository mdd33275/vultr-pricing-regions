## 「月額◯円〜」のカラクリ：長期契約の換算値、別枠のサーチャージ、通信量の上限

国内勢の最安値を並べると、Vultrの$3.50が高く見えたり安く見えたりして判断がぶれる。数字の土俵が違うからで、主なズレは4か所ある。

**契約期間の換算値か、月単位の実額か。** XServer VPSが掲げる2GB/3コア1,265円、4GB/4コア2,035円、8GB/6コア3,850円は、いずれも36ヶ月契約時の月額。1ヶ月単位で同じ額を払うことはできない。さくらのVPSは同じ2GBプランで「月額換算1,594円（年額一括）」と「月払い1,738円」の2つの数字を併記している。どちらも同じプランの価格で、支払い方で変わる。

**月額とは別に乗る費用。** GMOのクラウドVPSは1GB 858円からという表示のすぐ下に、プラン月額とは別にサーチャージ費が課金されると明記している。表の数字だけで総額は決まらない。

**通信量に上限があるか。** DDPS VPSは月間通信量がプランごとに1TBから7TBで頭打ちになる。ConoHa VPSは転送量0円・無制限を前面に出している。同じ「安いVPS」でも、月に何TB流すかで意味が変わる。

**SLAが全プランに付くか。** さくらのVPSの品質保証は4GB以上のプランが対象で、512MBから2GBは非対応。GMOはSLA 99.99%を全プランで掲げている。

Vultrの$3.50は長期契約の換算値ではなく、IPv4込みで地域による上乗せもない月額そのもの。ただし契約期間を延ばしても安くならない代わりに、長期縛りも発生しない。

## 用途別：512MBで足りるもの、2GB必要なもの

**軽いスクリプト、監視、検証環境。** 512MBで足りる。ただし前述のとおりNew Jersey限定なので、日本からの低遅延を求めるなら1GBの$5/月を使うことになる。

**WordPress、小規模サイト。** 国内勢の目安はメモリ2GB。ConoHa VPSは2GB/3コアを「基本的なWebサイトの運用に十分なスペック」と位置づけ、さくらのVPSは2GBを「一般的なWebサイトやWordPressの運用」向けとしている。1GBで動かないことはないが、プラグインを足していくと窮屈になる。Vultrで2GB帯を選ぶと1GBの次の価格帯に入るので、国内の2GBプラン（月払い1,738円など）と並べて比べる価値がある。

**AIエージェントの自托管。** ConoHa VPSはDify、n8n、OpenClaw、Hermes Agentといったツールの自托管を想定し、2GB/3コア・月1,259円の構成例を出している。PCを閉じても止まらない状態を作るのが目的なので、メモリ2GB・2コア以上が一つの線になる。Vultrでも同じ構成は組めるが、プラン選びの基準はこの線で考えればいい。
